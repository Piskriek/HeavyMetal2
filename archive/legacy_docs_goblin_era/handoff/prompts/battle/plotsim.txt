START FROM A CLEAN SLATE. Write ONE TypeScript module: the economy of a player's plot in a terraforming game, as pure deterministic functions with tests. No graphics, no DOM.

THE GAME. A scientist steps through a gate onto their plot on a desolate planet (about 1 km across, the gate at its centre) and builds machines. Power comes from the gate's junction box and spreads along relay pylons and power units. A rock drill mines ore from the ground; pixel machines use power (and most use ore) and pour coloured "pixels" into the air, each raising one of four fidelity metrics of the plot: texture (pxd), shape (vtx), light (lx), water (aq). As the metrics climb, the plot climbs six stages of graphical fidelity (stage 0 is the black-and-white world you land on). Each stage unlocks machines. It must be logical (every rule has a physical reason the player can guess), readable (the HUD can always say what is needed next) and paced so a session feels rewarding: the second stage in minutes, the last in a few hours.

DELIVERY: reply with exactly two fenced code blocks and only a few words around them: first `src/index.ts`, then `tests/plotsim.test.ts`. No other files are collected (a small preview page is welcome if your environment shows one: a top view of a plot with machines, the power reach circles and the HUD numbers, running the reference player below at 60x speed). When the tests pass, STOP.

RULES: TypeScript strict with noUncheckedIndexedAccess, no `any`, no DOM, no Date, no Math.random, no imports in src. The test file imports only `node:test`, `node:assert/strict` and `../src/index`. All state is plain JSON-serialisable data; every function is pure (returns new state, never mutates its input).

## The machines (the art is approved; implement exactly these seven)
| kind | name | does | power | ore | unlock |
|---|---|---|---|---|---|
| `drill` | Rock drill | mines ore from the ground (faster on rock and scree: the game passes the ground's richness 0..1) | draws | none (it makes ore) | stage 0 |
| `mill` | Texture mill | grinds ore into texture detail: raises `pxd` | draws | uses | stage 0 |
| `pylon` | Relay pylon | carries power further: a node of the power network | none | none | stage 0 |
| `press` | Shape press | stamps geometry finer: raises `vtx` | draws | uses | stage 1 |
| `power` | Power unit | burns ore to make electricity (steam, no pixels): supplies power and is a node of the network | supplies | uses | stage 1 |
| `projector` | Light projector | raises the light: raises `lx` | draws (the most) | none | stage 2 |
| `water` | Water maker | condenses water from gravel: raises `aq` | draws | uses | stage 3 |
Pixel machines (mill, press, projector, water) have a cartridge slot: a preset cartridge scales their output by the cartridge's affinity for their metric (the game passes `affinity`, default 1).

## The rules
- **Start:** 60 ore, stage 0, no machines; the 60 ore buy the first texture mill and the first rock drill. The plot never loses anything: metrics and stage only rise.
- **Power network:** the gate's junction box supplies `GATE.supply` kW and reaches `GATE.reach` metres. A pylon or power unit within reach of a connected node is connected and reaches its own `reach` from where it stands (chains outward). A machine is connected when it stands within reach of a connected node. Unconnected machines do not run. Supply = the gate + every connected, running power unit; demand = every connected machine that is on and draws; satisfaction = min(1, supply / demand) (1 with no demand); every drawing machine runs at the satisfaction. The gate alone runs about three average machines, so power units matter early.
- **Ore:** drills add ore at `mine * richness(x, z) * running`. Machines that use ore draw it from the plot's stock (the ore stock is plot-wide: the game shows it as heaps at the drills). If the stock is empty, ore-using machines (power units included) share what the drills bring in, evenly. The stock never goes below 0 and is capped at `ORE_CAP`. One drill on good ground (richness 0.8) mines more than one mill uses.
- **Metrics:** each running pixel machine adds `rate * running * affinity` points per second to its metric's points. A metric's LEVEL (0..100, what the HUD shows and the stages need) follows diminishing returns: `level = 100 * sqrt(points / TARGET)`, capped at 100 (doubling the level takes four times the points).
- **Stages:** placing the first pixel machine (stage 0) lifts the plot to stage 1 at once. Above that, the plot reaches stage n+1 when every metric in `STAGES[n+1]` is at or above its need: stage 2 `{ pxd: 15, vtx: 10 }`; stage 3 `{ pxd: 30, vtx: 25, lx: 15 }`; stage 4 `{ pxd: 50, vtx: 45, lx: 35, aq: 20 }`; stage 5 `{ pxd: 75, vtx: 70, lx: 60, aq: 50 }`; stage 6 `{ pxd: 100, vtx: 100, lx: 100, aq: 100 }`. Several stages can be reached in one step.
- **Building:** a machine costs ore; removing one refunds half its cost (rounded down). It stands within `plotRadius` of the gate, off the gate's pad (`GATE.pad` + its own radius from the gate), at least its radius + the other's radius + 1 m from every machine, within reach of a connected node; a drill needs ground richness of at least 0.2. Checks run in this order and the first that fails is the refusal: unlocked, inside the plot, off the gate's pad, room, power reach, ore in the ground (drills), the cost. Each refusal says why in plain words the HUD can show: "Unlocks at stage 2.", "Outside your plot.", "Too close to the gate.", "Too close to the shape press.", "Out of reach of the power network: build a relay pylon closer.", "Not enough ore in this ground.", "Needs 40 ore (you have 12).".
- You choose the numbers in `KINDS` (cost, draw kW, ore use, mining rate, metric rate, reach, radius), `GATE`, `ORE_CAP` and `TARGET` so the pacing test passes. Rough sizes: costs 10 to 120 ore, draws 2 to 10 kW, the gate 10 to 15 kW, reach 25 to 45 m, radius 1 to 2.5 m.

## API (implement exactly; you may add more exports)

```ts
export type Metric = 'pxd' | 'vtx' | 'lx' | 'aq';
export const METRICS: readonly Metric[];   // ['pxd', 'vtx', 'lx', 'aq']
export type MachineKind = 'drill' | 'mill' | 'pylon' | 'press' | 'power' | 'projector' | 'water';
export interface KindSpec {
  readonly kind: MachineKind; readonly name: string;
  readonly cost: number;        // ore
  readonly draw: number;        // kW while running; negative = supplies (the power unit)
  readonly oreUse: number;      // ore/s while running
  readonly mine: number;        // ore/s at richness 1 (drill only, else 0)
  readonly emits: Metric | null; readonly rate: number;   // points/s at full running
  readonly reach: number;       // metres as a network node (pylon, power unit), else 0
  readonly unlock: number;      // stage
  readonly slot: boolean;       // takes a cartridge
  readonly radius: number;      // footprint, metres
}
export const KINDS: Readonly<Record<MachineKind, KindSpec>>;
export const GATE: { readonly supply: number; readonly reach: number; readonly pad: number };
export const ORE_CAP: number;
export const TARGET: Readonly<Record<Metric, number>>;   // points for level 100
export const STAGES: readonly (Readonly<Partial<Record<Metric, number>>>)[];  // index = stage, 0..6 (0 and 1: {})

export interface Machine { readonly id: number; readonly kind: MachineKind; readonly x: number; readonly z: number; readonly yaw: number; readonly on: boolean; readonly cartridge: string | null; readonly built: number }
export interface PlotState {
  readonly v: 1; readonly time: number; readonly ore: number;
  readonly points: Readonly<Record<Metric, number>>;
  readonly stage: number; readonly machines: readonly Machine[]; readonly nextId: number;
}
export interface Env {
  readonly gate: { readonly x: number; readonly z: number };
  readonly plotRadius: number;
  richness(x: number, z: number): number;                 // 0..1
  affinity?(cartridge: string, metric: Metric): number;    // default 1
}
export type PlotEvent = { readonly type: 'stage-up'; readonly stage: number } | { readonly type: 'ore-out' } | { readonly type: 'underpowered' };

export function newPlot(): PlotState;
export function level(s: PlotState, m: Metric): number;   // 0..100
export function network(s: PlotState, env: Env): { readonly connected: ReadonlySet<number>; readonly supply: number; readonly demand: number; readonly satisfaction: number };
/** How hard each machine runs now, 0..1 (0: off, unconnected, or starved). */
export function running(s: PlotState, env: Env): ReadonlyMap<number, number>;
export function canPlace(s: PlotState, env: Env, kind: MachineKind, x: number, z: number): { readonly ok: true } | { readonly ok: false; readonly why: string };
export function place(s: PlotState, env: Env, kind: MachineKind, x: number, z: number, yaw: number): PlotState;  // throws with the reason if it may not
export function remove(s: PlotState, id: number): PlotState;
export function setOn(s: PlotState, id: number, on: boolean): PlotState;
export function setCartridge(s: PlotState, id: number, cartridge: string | null): PlotState;  // throws on a machine without a slot
/** Advances dt seconds (split into steps of at most 1 s inside). Events: each stage reached; 'ore-out' when the stock is empty while machines need ore (once; again only after it recovered); 'underpowered' when satisfaction first drops below 1 (again only after it recovered). */
export function step(s: PlotState, env: Env, dt: number): { readonly state: PlotState; readonly events: readonly PlotEvent[] };
/** What the next stage needs, and how close it is: the smallest level/need over its metrics, 0..1. Null at stage 6. */
export function nextStage(s: PlotState): { readonly stage: number; readonly needs: Readonly<Partial<Record<Metric, number>>>; readonly progress: number } | null;
/** Net rates for the HUD: ore/s, points/s per metric, power. */
export function rates(s: PlotState, env: Env): { readonly ore: number; readonly points: Readonly<Record<Metric, number>>; readonly supply: number; readonly demand: number };
/** A saved state, checked: junk falls back to newPlot(); bad machines are dropped; numbers clamped. */
export function loadPlot(raw: unknown): PlotState;
```

## Acceptance tests (copy unchanged, then add your own: every refusal reason, chains of pylons, a power unit with no ore, cartridges, events once, determinism, large dt equals small steps)

```ts
import test from 'node:test';
import assert from 'node:assert/strict';
import { KINDS, GATE, STAGES, METRICS, newPlot, level, network, running, canPlace, place, remove, step, nextStage, loadPlot, type Env, type MachineKind, type PlotState } from '../src/index';

const env: Env = { gate: { x: 0, z: 0 }, plotRadius: 500, richness: () => 0.8 };
const poor: Env = { ...env, richness: () => 0.05 };
const run = (s: PlotState, seconds: number, e: Env = env) => { let st = s; const events: string[] = []; for (let t = 0; t < seconds; t++) { const r = step(st, e, 1); st = r.state; for (const ev of r.events) events.push(ev.type === 'stage-up' ? `stage-${ev.stage}` : ev.type); } return { s: st, events }; };

test('seven machines, unlocked in order, and a fresh plot', () => {
  assert.deepEqual(Object.keys(KINDS).sort(), ['drill', 'mill', 'power', 'press', 'projector', 'pylon', 'water']);
  assert.deepEqual([...METRICS], ['pxd', 'vtx', 'lx', 'aq']);
  assert.deepEqual((['drill', 'mill', 'pylon', 'press', 'power', 'projector', 'water'] as MachineKind[]).map((k) => KINDS[k].unlock), [0, 0, 0, 1, 1, 2, 3]);
  assert.equal(KINDS.mill.emits, 'pxd'); assert.equal(KINDS.press.emits, 'vtx'); assert.equal(KINDS.projector.emits, 'lx'); assert.equal(KINDS.water.emits, 'aq');
  assert.ok(KINDS.power.draw < 0 && KINDS.drill.mine > 0 && KINDS.pylon.reach > 0);
  assert.equal(STAGES.length, 7);
  const s = newPlot();
  assert.equal(s.ore, 60); assert.equal(s.stage, 0); assert.equal(s.machines.length, 0);
});

test('the first pixel machine lifts the plot to stage 1; building pays ore and says why it may not', () => {
  let s = newPlot();
  assert.equal(canPlace(s, env, 'press', 10, 0).ok, false, 'the press waits for stage 1');
  const locked = canPlace(s, env, 'press', 10, 0); assert.ok(!locked.ok && /stage/i.test(locked.why));
  const pad = canPlace(s, env, 'mill', 0.5, 0); assert.ok(!pad.ok && /gate/i.test(pad.why));
  const far = canPlace(s, env, 'mill', 90, 0); assert.ok(!far.ok && /reach|power|pylon/i.test(far.why));
  s = place(s, env, 'mill', 10, 0, 0);
  assert.equal(s.stage, 1);
  assert.equal(s.ore, 60 - KINDS.mill.cost);
  const close = canPlace(s, env, 'drill', 10.5, 0.5); assert.ok(!close.ok && /close|room|space/i.test(close.why));
  const dry = canPlace(s, poor, 'drill', 0, 12); assert.ok(!dry.ok && /ore/i.test(dry.why));
  const id = s.machines[0]!.id;
  const back = remove(s, id);
  assert.equal(back.ore, s.ore + Math.floor(KINDS.mill.cost / 2));
  assert.equal(back.stage, 1, 'a plot never loses its stage');
});

test('power: the gate reaches so far and supplies so much; pylons carry it on; power units add to it', () => {
  let s = newPlot();
  s = { ...s, ore: 10000 };
  s = place(s, env, 'mill', 10, 0, 0);
  const n0 = network(s, env);
  assert.ok(n0.connected.has(s.machines[0]!.id));
  assert.equal(n0.supply, GATE.supply);
  // a pylon at the edge of the gate's reach carries power further out
  const edge = GATE.reach - 2;
  s = place(s, env, 'pylon', 0, edge, 0);
  const out = edge + KINDS.pylon.reach - 3;
  assert.ok(canPlace(s, env, 'drill', 0, out).ok, 'within the pylon\'s reach');
  s = place(s, env, 'drill', 0, out, 0);
  assert.ok(network(s, env).connected.has(s.machines[2]!.id));
  // more demand than the gate supplies: everything slows; a power unit restores it
  s = { ...s, stage: 1 };
  for (const [x, z] of [[-10, 0], [0, -10], [8, 8]] as const) s = place(s, env, 'press', x, z, 0);
  const tight = network(s, env);
  assert.ok(tight.demand > tight.supply && tight.satisfaction < 1);
  s = place(s, env, 'power', -8, -8, 0);
  assert.ok(network(s, env).supply > tight.supply);
});

test('ore: drills fill the stock, machines empty it, it never goes below zero, starved machines slow down', () => {
  let s = place(newPlot(), env, 'mill', 10, 0, 0);
  const starve = run({ ...s, ore: 0 }, 30);
  assert.equal(starve.s.ore, 0);
  assert.equal(running(starve.s, env).get(starve.s.machines[0]!.id), 0, 'no ore, no milling');
  assert.ok(starve.events.includes('ore-out'));
  s = place({ ...s, ore: 100 }, env, 'drill', -10, 0, 0);
  const fed = run({ ...s, ore: 0 }, 120);
  assert.ok(level(fed.s, 'pxd') > 0, 'the drill feeds the mill');
  const richer = run(s, 120), poorer = run(s, 120, poor);
  assert.ok(richer.s.ore > poorer.s.ore, 'rich ground mines faster');
});

test('metrics rise only from running pixel machines, with diminishing returns, and stages follow them', () => {
  let s = place(newPlot(), env, 'mill', 10, 0, 0);
  s = { ...s, ore: 5000 };
  const a = run(s, 600).s, b = run(s, 2400).s;
  assert.ok(level(a, 'pxd') > 0 && level(a, 'vtx') === 0 && level(a, 'lx') === 0);
  assert.ok(level(b, 'pxd') < 4 * level(a, 'pxd') + 1e-9, 'four times the time is at most four times the level');
  assert.ok(level(b, 'pxd') >= 1.9 * level(a, 'pxd') - 1e-9, 'diminishing, not stalling (sqrt)');
  assert.equal(nextStage(a)!.stage, 2);
  assert.ok(nextStage(a)!.progress < 1 && Object.keys(nextStage(a)!.needs).sort().join() === 'pxd,vtx');
  for (const m of METRICS) assert.ok(level(b, m) <= 100);
});

test('saves round-trip, junk is refused, and the same inputs give the same plot', () => {
  let s = place(newPlot(), env, 'mill', 10, 0, 0);
  s = run(s, 300).s;
  assert.deepEqual(loadPlot(JSON.parse(JSON.stringify(s))), s);
  assert.deepEqual(loadPlot(null), newPlot());
  assert.deepEqual(loadPlot({ v: 1, ore: 'lots', machines: [{ kind: 'chimney' }] }).machines, []);
  assert.deepEqual(run(s, 200).s, run(s, 200).s);
  const big = step(s, env, 5).state, small = run(s, 5).s;
  assert.ok(Math.abs(big.ore - small.ore) < 1e-6 && Math.abs(level(big, 'pxd') - level(small, 'pxd')) < 1e-6, 'a 5 s step equals five 1 s steps');
});

test('pacing: a plain player reaches stage 2 in minutes and stage 6 in a few hours', () => {
  // the reference player: every 15 s of game time it builds the next machine on its list as soon as it may, at the first free spot on rings round the gate
  const WISH: MachineKind[] = ['mill', 'drill', 'drill', 'press', 'power', 'drill', 'mill', 'press', 'pylon', 'projector', 'power', 'drill', 'mill', 'press', 'projector', 'pylon', 'water', 'power', 'drill', 'water', 'mill', 'press', 'projector', 'water', 'power', 'pylon', 'drill', 'mill', 'press', 'projector', 'water', 'power'];
  let s = newPlot(), wish = 0;
  const reached: number[] = [];
  for (let t = 0; t < 5 * 3600 && s.stage < 6; t++) {
    if (t % 15 === 0 && wish < WISH.length) {
      const kind = WISH[wish]!;
      found: for (let ring = 8; ring <= 220; ring += 7) for (let deg = 0; deg < 360; deg += 15) {
        const x = Math.cos((deg * Math.PI) / 180) * ring, z = Math.sin((deg * Math.PI) / 180) * ring;
        if (canPlace(s, env, kind, x, z).ok) { s = place(s, env, kind, x, z, 0); wish++; break found; }
      }
    }
    const r = step(s, env, 1); s = r.state;
    for (const e of r.events) if (e.type === 'stage-up') reached[e.stage] = s.time;
  }
  const at = (n: number) => reached[n] ?? Infinity;
  assert.ok(at(2) >= 300 && at(2) <= 900, `stage 2 at ${at(2)} s (5 to 15 min)`);
  assert.ok(at(3) >= 900 && at(3) <= 2400, `stage 3 at ${at(3)} s (15 to 40 min)`);
  assert.ok(at(4) >= 1800 && at(4) <= 4800, `stage 4 at ${at(4)} s (30 to 80 min)`);
  assert.ok(at(6) >= 9000 && at(6) <= 18000, `stage 6 at ${at(6)} s (2.5 to 5 h)`);
});
```
