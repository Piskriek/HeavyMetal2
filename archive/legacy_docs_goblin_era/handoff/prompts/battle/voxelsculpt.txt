TASK "voxelsculpt": the editing engine behind a 3D voxel sculpting tool (like MagicaVoxel / Minecraft-style editors). It is pure logic that a UI drives with pointer rays. A model is:
type V3 = [number, number, number];
interface Model { size: V3; /* each 1..96 */ palette: { color: V3 }[]; /* cell value i = palette[i-1] */ cells: Uint8Array /* x fastest, then y, then z; 0 = empty; y is up */ }
(Your file must NOT import anything; declare these types itself and export them.)

1. RAYCAST. `raycast(model, origin: V3, dir: V3, maxDist = 400): { cell: V3; normal: V3; before: V3 | null; dist: number } | null` in voxel units (cell (x,y,z) spans x..x+1 etc). Amanatides-Woo DDA. Returns the first SOLID cell hit, the axis-aligned face normal that was entered, `before` = the empty cell in front of that face (null if outside the grid), dist along dir. A ray that starts inside the grid in a solid cell hits it at dist 0. A ray that starts outside must be clipped to the grid box first. A ray through an all-empty grid returns null. Also `raycastGround(origin, dir, y = 0)`: intersection with the plane y=y as { point: V3 } | null, so you can build on an empty grid.

2. BRUSHES. `type BrushShape = 'cube' | 'sphere' | 'disc' | 'line'`. `brushCells(shape, centre: V3, size: number, normal: V3, extra?: { to?: V3 }): V3[]` lists the integer cells a dab covers, in a stable order, no duplicates, not clipped to the grid: cube = size x size x size centred on centre (even sizes extend one more to the positive side); sphere = cells whose centres are within size/2; disc = a flat circle of diameter `size` and thickness 1, lying in the plane perpendicular to the dominant axis of `normal`; line = 3D Bresenham from centre to extra.to.

3. SESSION. `class SculptSession { constructor(model: Model, opts?: { maxHistoryCells?: number /* default 2_000_000 */ }) }`:
 - `model(): Model` returns the CURRENT model (a new object with a copy of the cells each call is fine).
 - `symmetry: { x: boolean; y: boolean; z: boolean; radial: number /* 0 or 1 = off, else N-fold around the y axis through the grid centre */ }` public field; every dab is repeated for the mirrored/rotated copies (mirror about the grid centre planes; radial rotates by 360/N degrees, rounding to the nearest cell); the union is applied once (no double application).
 - `beginStroke(label: string)`, `dab(mode: 'add'|'remove'|'paint'|'smooth', cells: V3[], colour: number)`, `endStroke(): boolean` (true if anything changed). Modes: add writes `colour` into EMPTY cells only; remove clears solid cells; paint recolours SOLID cells only; smooth removes solid cells that have at most 2 solid face neighbours and adds empty cells (colour = the most common neighbouring colour) that have at least 5 solid face neighbours (computed from the state before the dab). If a selection is active (see 4), dabs only change cells inside it. Cells outside the grid are ignored.
 - Every stroke is ONE undo step recorded as a diff list { index, before, after }[] (only cells that changed, merged per cell across dabs: the stroke's `before` is the value before the first dab). `undo(): boolean`, `redo(): boolean`, `canUndo`, `canRedo`, `history(): { label: string; cells: number }[]`. Starting a new stroke clears redo. Drop the oldest steps when total recorded cells exceed maxHistoryCells.
 - `strokeFromSamples(label, mode, shape, size, colour, samples: { point: V3; normal: V3 }[], spacing = 1)`: convenience that resamples a pointer path (consecutive samples further apart than `spacing` get intermediate dabs by linear interpolation of the point, rounding to cells) and runs a whole stroke.
 - `resize(size: V3, anchor: 'min' | 'centre')` as one undoable step (cells keep their positions relative to the anchor; cut cells outside).

4. SELECTION. Held by the session: `selection: Selection | null` where Selection is a Set of linear cell indices wrapped with helpers. Functions (all also methods of the session where they change the model, each ONE undo step): `selectBox(a, b, mode: 'replace'|'add'|'subtract')`, `selectSphere(c, r, mode)`, `selectWand(cell, mode, opts?: { tolerance?: 'exact'|'any' })` flood fills 6-connected SOLID cells of the same colour ('any' = any solid colour), `selectAll()`, `selectNone()`, `invertSelection()`, `growSelection()` / `shrinkSelection()` (6-neighbourhood, 1 cell), `selectionBounds(): { min: V3; max: V3 } | null`. Operations on the selection: `deleteSelection()`, `fillSelection(colour)` (solid cells in it get the colour, and if `fillEmpty` is true also empty ones), `moveSelection(dx, dy, dz)` (the selected solid cells and the selection itself move; cells that would leave the grid are dropped; destination overwrites), `copySelection(): Clip | null` where Clip = { size: V3; cells: { offset: V3; value: number }[] } relative to the selection min, `paste(clip, at: V3, opts?: { onlyEmpty?: boolean })`, `rotateSelection(axis: 'x'|'y'|'z', quarterTurns: number)` about the selection bounds centre (integer, exact, 4 turns = identity), `flipSelection(axis)`, `scaleSelection(factor: 2 | 0.5)` (2 = every voxel becomes 2x2x2, 0.5 = keep the majority colour of each 2x2x2 block; drop what does not fit).

5. PALETTE. Pure functions returning a new model: `paletteAdd(model, color): { model; index }` (index is the 1-based cell value, max 255, returns the existing index when the colour is already present), `paletteRemove(model, index, replaceWith)` (cells with that value become replaceWith (0 = empty), higher indices shift down and cells are remapped), `paletteMove(model, from, to)` (reorder, remap cells), `paletteMerge(model, tolerance = 0.02)` (merge entries whose colours are within `tolerance` Euclidean distance, remap, keep the first), `paletteUse(model): number[]` voxels per entry, `paletteSort(model, by: 'hue'|'lightness'|'use')`. Colours are RGB 0..1.
