## 1. Executive Decision: Why `Stage 0a (Wireframe) -> Stage 0b (1-Bit Flat Facets)` Wins

Francois identified two huge visual upgrades for the early Moon experience:
1. **Perspective in the 1-Bit Dither Look:** Because a 4x4 Bayer dither pattern has fixed dot pitch, a smoothly shaded terrain slope has no geometric scale cue—it looks flat at distance. Adding **flat-shaded 3D polygon facets (`dFdx/dFdy` per-face normals)** underneath the 1-bit threshold gives the eye real triangles that **foreshorten and shrink with distance (`1/z`)**, restoring immediate 3D perspective.
2. **Starting in Pure Wireframe for the "Big-Win" First Machine Payoff:** Stepping onto the Moon when it hasn't even allocated solid surfaces yet—just hidden-line vector wireframes and a converging ground grid—and then watching your very first running machine **fill the world with solid 1-bit faceted surfaces** makes the first 3 minutes on the Moon unforgettable.

**Architectural Mapping Decision (Approved):**
Keep the canonical **`Stage 0` to `Stage 6`** numbering across the codebase (preserving all quest triggers, `S-2` to `S-6` voice lines, monster era tables, and tests), and split `Stage 0` into two sub-states driven purely by whether the plot has received its first machine pulse of `S`:
- **`Stage 0a` — Cold Unallocated Arrival (`stage === 0 && totalS < 0.015`):** **Hidden-Line Vector Wireframe** (*Battlezone* / *Elite* look). Lasts only the first 2–4 minutes on the Moon until the first machine (`Texture Mill` / `Shape Press`) starts running.
- **`Stage 0b` — First Surface Allocation (`stage === 0 && totalS >= 0.015`):** **1-Bit Flat-Faceted Dither** (*Obra Dinn* world-locked dither over *Superhot*-style flat-shaded 3D facets). Triggered by a dramatic radial scan-wave the moment the first machine ticks!

## 4. Exact Shader Implementation Notes for `Brief 27`

1. **`uWireframeMix` Uniform (`Stage 0a -> Stage 0b` Transition):**
   - Define `uWireframeMix = clamp(1.0 - smoothstep(0.002, 0.020, Pxd + Vtx), 0.0, 1.0)` when `stage === 0`.
   - When the first machine ticks, trigger the **Radial Volumetric Scan-Wave (`P1-LIGHT-04`, `radius = 0 -> 350 m` over `3.5 s`)**: inside the expanding ring, `uWireframeMix` drops to `0.0` (resolving into **Stage 0b 1-Bit Flat-Faceted Dither**); outside the ring, the world remains **Stage 0a Wireframe** until the wave passes!
   - **Color Bypass Rule (`0.5 Alpha Mark`):** Just as in the current post pass, fragments written with `alpha < 0.5` (or tagged emissive: pixel plumes, the `15 m` Twin Gate amber coil pool, build hologram ghosts, and HUD) bypass wireframe/monochrome quantization so gameplay-critical color cues always pop against the dark vector Moon.
2. **Flat-Faceted Normal Calculation for `Stage 0b` and `Stage 1`:**
   - In the ground/prop fragment shader, compute `vec3 flatNormal = normalize(cross(dFdx(vWorldPos), dFdy(vWorldPos)));` and blend `vec3 N = normalize(mix(flatNormal, vSmoothNormal, smoothstep(0.20, 0.55, Vtx)));`.
   - Feed `dot(N, uSunDir)` into the world-locked cylindrical Bayer dither threshold (`Stage 0b`) and 16-color EGA ramp (`Stage 1`) so every triangle face renders as a crisp, perspective-correct flat facet!
