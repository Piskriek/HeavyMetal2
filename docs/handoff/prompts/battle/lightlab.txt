Build a single-page web app (Vite + TypeScript + three.js, npm packages allowed, must run with `npm run dev` and `npm run build`) called "Light Lab": it shows the SAME small 3D scene under many different lighting, post-processing and render setups so a designer can pick the best looks.

SCENE (procedural, no image files): a small low-poly tropical island (displaced icosphere / terrain with vertex-coloured sand, grass, rock) in a sea plane with gentle animated waves, a few voxel-style palm trees (box trunks, spiky leaf cards), mossy rocks, a wooden dock, a barrel, and a blocky voxel goblin character (boxes: green head with big pointed ears, blue jacket, brown belt, boots) standing on a small plinth in the foreground. Use MeshStandardMaterial / MeshPhysicalMaterial with sensible roughness and metalness so lighting differences are obvious (a metal barrel band, glossy wet rocks). Slowly orbiting camera, mouse orbit controls.

LIGHTING SETUPS are DATA, not code. Define `interface LightSetup { id: string; name: string; sun: { color: string; intensity: number; azimuthDeg: number; elevationDeg: number; shadowSoftness: number; shadowMapSize: number }; hemi: { sky: string; ground: string; intensity: number }; ambient: { color: string; intensity: number }; fill?: { color: string; intensity: number; position: [number, number, number] }; extraLights?: { type: 'point'|'spot'; color: string; intensity: number; position: [number,number,number]; distance: number }[]; sky: { top: string; horizon: string; bottom: string; sunGlow: number }; fog: { color: string; density: number }; water: { color: string; opacity: number; roughness: number }; toneMapping: 'none'|'linear'|'reinhard'|'cineon'|'aces'|'agx'|'neutral'; exposure: number; post: { bloom: { strength: number; radius: number; threshold: number }; vignette: { darkness: number; offset: number }; saturation: number; contrast: number; lift: string; gamma: string; gain: string; ssao: { enabled: boolean; radius: number; intensity: number }; fxaa: boolean; grain: number } }`. Provide at least 16 carefully art-directed setups: Noon clear, Golden hour, Sunset blaze, Tropical dawn, Overcast, Storm front, Blue hour, Moonlit night, Volcanic ash, Neon dusk, Foggy morning, Studio white (high-key, soft, clean white-wall look with very soft shadows), Toon flat (strong rim, posterised look via colour grading), Cinematic teal and orange, Candle and lantern night (point lights, warm), Clean product shot. Make them genuinely beautiful and different from each other; spend effort on colour harmony.

UI (minimalist white-wall style: off-white #f8f7f2 background, 1px hairline borders #dcdad2, square corners, Inter font, small uppercase tracked labels, one terracotta accent #c56443; no shadows, no glows, no rounded corners): a left column with the list of setups (name + a small live colour swatch strip), a main viewport, a right inspector with sliders and colour pickers for EVERY field of the selected LightSetup (live editing), a time-of-day slider that moves the sun and re-tints sky/fog smoothly, a quality selector (Low / Medium / High / Ultra: pixel ratio, shadow map size 1024 to 4096, SSAO and bloom on/off), a "compare" mode that splits the screen between two chosen setups with a draggable divider, buttons "Copy JSON" (copies the selected LightSetup as JSON) and "Screenshot" (downloads a PNG), an FPS counter. Use EffectComposer with RenderPass, SSAOPass or GTAO if available, UnrealBloomPass, a custom ShaderPass for vignette + colour grading (lift/gamma/gain, saturation, contrast, grain), OutputPass. Keep it smooth (60 fps on a strong desktop GPU) and put all setups in `src/setups.ts`.
