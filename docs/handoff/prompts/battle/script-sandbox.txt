WHAT TO BUILD (packages/script/src/index.ts exports `createScriptHost(opts?: { limits?: Partial<ScriptLimits> }): ScriptHost`, defaults callBudgetMs 100 and opBudget 2_000_000):
1. compile(source): TypeScript -> JavaScript with the `typescript` package. Return diagnostics (line/column 1-based in the user's source) for syntax errors AND type errors, never throw. Type-check by creating a ts.Program on an in-memory CompilerHost with two files: user.ts (the source) and ambient.d.ts (= the string returned by typings('Mechanic'), see 4), compiler options {strict:true, target:ES2022, module:ESNext, lib:['lib.es2022.d.ts']} (read lib files from the typescript package folder with fs). Unknown globals like window, document, fetch, process must therefore be type errors. ALSO walk the AST and refuse: import declarations, `export ... from`, calls to require() or eval(), `new Function(...)` / Function(...) calls. Output JS with ts.transpileModule (module CommonJS) so `export function f` becomes a property on an `exports` object.
2. The sandbox: QuickJS compiled to WebAssembly: npm package `quickjs-emscripten` (use `getQuickJS()` with a top-level await so createScriptHost stays synchronous). One fresh runtime+context per loaded script. In each context, before running the script, evaluate a prelude that: replaces Math.random with a function that throws Error('Math.random is disabled: use ctx.rng'), replaces globalThis.Date with something that throws Error('Date is disabled: use ctx.tick') when called or constructed, and Object.freeze()s Object.prototype, Array.prototype, Function.prototype and the prototypes of String, Number and Boolean so a script cannot pollute them. Use runtime.setInterruptHandler for the budgets: count handler calls and abort when the count exceeds opBudget, or when wall time since the call started exceeds callBudgetMs. Also runtime.setMemoryLimit(16 MB) and setMaxStackSize.
3. Marshalling for every call(script, member, ctx, ...args): build the ctx inside the VM for that call: plain values (self, tick, dt, args) copied as JSON; functions (ctx.set, spawn, despawn, emit, log, vars.read/write/evaluate, world.query/get/has/alive/getResource/presetOf, rng.next/int/pick/fork/state/restore) become VM functions made with vm.newFunction that call the host ctx function and marshal the result back as JSON. Return values come back as JSON (Value). A member not in SCRIPT_INTERFACES[iface] makes call return {ok:false,error:'...'}; a member the script does not export is a successful no-op (ok:true, value undefined). call() never throws: any exception or budget overrun gives {ok:false, error}, sets script.faulted=true and script.lastError. A faulted script returns {ok:false, error:'script is faulted: reload it'} until reload().
4. typings(iface): returns a .d.ts string declaring ambient `interface ScriptContext` (plus Rng, Value, Params) copied from the contract, and the interface named iface (for example `interface Mechanic`). It must contain 'interface ScriptContext', 'rng' and the member names of the interface, and must not contain the word window.
5. load(preset, iface): throws ScriptError if iface is not in SCRIPT_INTERFACES, if the preset has no script, or if compile fails; returns a LoadedScript {presetId, instance, faulted, lastError}. reload(script, source): compile and load the new source; on a compile error THROW and leave the old script untouched; on success return a fresh un-faulted script. dispose(): dispose all VMs.
Keep files small (<300 lines): compile.ts, sandbox.ts, marshal.ts, typings.ts, host.ts, index.ts. Comments say WHY. No other runtime dependencies than quickjs-emscripten and typescript.

function makeCtx(over: Partial<ScriptContext> = {}): ScriptContext & { writes: unknown[]; emitted: unknown[]; logs: unknown[] } {
  const writes: unknown[] = [], emitted: unknown[] = [], logs: unknown[] = [];
  let r = 0;
  const base: ScriptContext = {
    self: { id: 's1', params: { power: 3 } }, tick: 7, dt: 1 / 120,
    rng: {
      next: () => (r = (r + 0.25) % 1), int: (a: number) => a, pick: <T>(x: readonly T[]) => x[0] as T,
      fork: () => makeCtx().rng, state: () => [r], restore: () => undefined,
    },
    vars: { read: () => 1, write: () => undefined, evaluate: () => 0 },
    world: { query: () => [1, 2], get: () => ({ x: 1 }), has: () => true, alive: () => true, getResource: () => null, presetOf: () => undefined },
    set: (e: number, c: string, v: Readonly<Record<string, Value>>) => { writes.push([e, c, v]); },
    spawn: () => 1, despawn: () => undefined,
    emit: (n: string, p?: Value) => { emitted.push([n, p]); },
    log: (...p: Value[]) => { logs.push(p); },
  };
  return Object.assign(base, over, { writes, emitted, logs });
}

test('sandbox: scripts cannot change the host (frozen builtins, no shared state between scripts)', () => {
  const host = createScriptHost();
  const a = host.load(preset('let n = 0; export function evaluate(): number { return ++n; }', 'a'), 'Rule');
  const b = host.load(preset('let n = 0; export function evaluate(): number { return ++n; }', 'b'), 'Rule');

});

test('limits: an infinite loop is stopped, the script is marked faulted, and the host survives', () => {

test('reload: live editing swaps behaviour, clears a fault, keeps state isolated', () => {
  const host = createScriptHost();
  const s = host.load(preset('export function evaluate(): number { return 1; }'), 'Rule');
