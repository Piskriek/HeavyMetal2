TASK (TypeScript, pure and deterministic): "texgraph": procedural PBR textures as DATA. A texture is a small graph of combinable nodes (noise, cellular, patterns, warps, blends, ramps) that outputs the PBR channels of a SEAMLESSLY TILING surface. It replaces image files: every layer and every parameter must be an editable number, colour or choice, so it can be customised, randomized and shared as JSON. MODEL (types.ts)
A graph is { id, name, nodes: TexNode[], out: { albedo?: string; height?: string; roughness?: string; ao?: string; emissive?: string; metallic?: string } } where each `out` value is a node id. Every node has an id, a `type` and its params; nodes reference other nodes by id in `in`, `a`, `b`, `mask`, `warp` fields. Node outputs are either 'scalar' (one float 0..1 per pixel) or 'color' (r,g,b 0..1). Evaluation is on a size x size grid (default 128) over the unit square; EVERY spatial node must be periodic with period 1 so the result tiles perfectly (use integer cell counts and wrap lattice coordinates).
Node vocabulary (implement all):
 sources: noise {scale: int cells 1..64, octaves 1..8, lacunarity 2, gain 0.5, kind: 'value'|'gradient', seed} (fractal, periodic); cellular {scale int, jitter 0..1, mode: 'f1'|'f2'|'edge'|'cellId', seed} (periodic Worley); grain {seed} (white noise per pixel); stripes {count int, angle in 90 degree steps 0|90, softness 0..1, duty 0..1}; checker {countX int, countY int, softness}; bricks {rows int, cols int, mortar 0..0.3, offset 0..1, jitter 0..1, seed}; chevrons {count int, angle 0..1, thickness 0..1, softness}; gradient {axis 'x'|'y'|'radial', repeat int}; constant {value}; colorConstant {r,g,b}.
 ops: warp {in, warp: node, amount 0..0.3} (domain warp, wrapped); blend {a, b, mask?: node, mode: 'mix'|'add'|'multiply'|'min'|'max'|'overlay'|'screen'|'difference', amount 0..1}; levels {in, inLow, inHigh, gamma, outLow, outHigh}; curve {in, points: [x,y][]} (piecewise linear, sorted); invert {in}; threshold {in, at, softness}; ramp {in: scalar node, stops: {at, r,g,b}[]} (scalar to colour); mapColor {in: color node, tint r,g,b, strength} ; heightToNormal {in: scalar height, strength} (finite differences with wrap, outputs a colour node whose r,g are the tangent-space normal xy in 0..1 and b = z); heightToAO {in, radius int 1..8, strength}; scaleBias {in, scale, bias}; mix of channels is not required.
FUNCTIONS
1. evaluate.ts: evaluateGraph(graph, opts?: { size?: number; seed?: number }): { size: number; albedo?: Float32Array /* rgb interleaved */; height?: Float32Array; normal?: Float32Array /* rg interleaved */; roughness?: Float32Array; ao?: Float32Array; emissive?: Float32Array; metallic?: Float32Array }. The opts.seed is added to every node's own seed so one number rerolls a whole texture. Same inputs give bit-identical output. If out.height is set, normal is derived from it with strength 1 unless a node 'normal' output exists (out may also have `normal`: a node id of a heightToNormal node). Cycles, missing ids and type mismatches must give clear errors from validateGraph (not exceptions from evaluate: evaluate throws only for invalid graphs and says why).
2. validate.ts: validateGraph(g: unknown): { ok: boolean; errors: string[] } with readable sentences ("node 'rock': 'warp' refers to 'wobble' which does not exist"); never throws; checks ranges, ids unique, no cycles, scalar/color types match.
3. stats.ts: channelStats(data: Float32Array, size, channels = 1): { mean: number[]; std: number[]; seam: number } where seam is the mean absolute difference between opposite edges (left vs right column, top vs bottom row) so tiling can be asserted (must be below 0.02 for a periodic texture of 128 px); frequencyFingerprint(data, size): number[] (8 bins of radial energy of a simple DFT of the luminance on a 32x32 downsample, normalised to sum 1), fingerprintDistance(a, b): number.
4. random.ts: randomizeGraph(g, seed, amount 0..1): new graph with numeric params jittered within their legal ranges (never changing node ids or structure) and seeds changed; same inputs same output.
5. presets.ts: exportable example graphs `TEXTURE_PRESETS`: 'basalt' (dark blue-grey, cellular cracks warped by noise, rough), 'tarmac' (dark grain plus fine gravel speckle, medium roughness), 'sand' (warm beige, fine grain plus soft wind ripples via stripes warped by noise), 'cobble' (cellular f2-f1 edges as height, wet low roughness in the stones, dark joints), 'grass' (green, two noise scales plus fine grain, no visible grid), each a graph of at least 5 nodes.
TESTS you write (must pass): periodicity: every preset has seam < 0.02 on albedo and height; determinism; validateGraph error messages for a missing id, a cycle, wrong type; each node type evaluated in isolation gives values in range 0..1 and is not constant (except constants); cellular f1 has lower mean than f2; checker with countX=countY=4 has exactly mean 0.5; heightToNormal of a flat height gives normal (0.5,0.5); randomizeGraph keeps structure and validates, differs from the original, is deterministic; fingerprints of 'basalt' and 'sand' differ (distance > 0.05) while a graph and the same graph with another seed are closer to each other than to the other preset; all presets evaluate in under 400 ms each at size 128.
