TASK (TypeScript, pure): "tracklayouts": 14 hand-designed race track layouts as data, plus the geometry checks that prove each one is valid. This is a creative geometry task: think like a track designer. Each layout is a closed loop of control points on a flat island of 256 x 256 metres (x and z from -110 to 110 are usable), driven in increasing index order, with a road width. A smooth centreline is made from the control points with Chaikin corner cutting (2 iterations, closed) and the road is that line with half-width on each side.

Project: Node 20+, ESM, TypeScript strict incl. noUncheckedIndexedAccess/noUnusedLocals, tsx, typescript, @types/node. Code in packages/tracklayouts/src/, tests in packages/tracklayouts/tests/.
