One TypeScript module for a three.js game: `src/index.ts` (package @hm/batcher) and `tests/batcher.test.ts` (node:test, runs headless: no renderer, no DOM). Then STOP.
RULES: strict TS (noUncheckedIndexedAccess), no any. Imports only `three`. Deterministic: no Date or Math.random.
WHY: a moon base has hundreds of building pieces, and each kind of piece is a few meshes, one per material. Cloning a group per piece costs thousands of draw calls on a GTX 950M. Batch them: ONE THREE.InstancedMesh per (key, part), so draw calls = sum over the keys in use of their part count.
API:
export interface Part { readonly geometry: THREE.BufferGeometry; readonly material: THREE.Material }
export class Batcher {
  constructor(root: THREE.Object3D, source: (key: string) => readonly Part[]); // source is called once per key, the first time a key is used; the parts are shared, never disposed by the batcher
  set(id: number, key: string, matrix: THREE.Matrix4): void; // add, move or re-key one instance
  remove(id: number): void; // unknown ids are ignored
  tint(id: number, color: THREE.Color | null): void; // per-instance colour (instanceColor); null = white; kept through moves and swaps
  has(id: number): boolean; matrixOf(id: number): THREE.Matrix4 | null;
  readonly drawCalls: number; // InstancedMeshes in root with count > 0
  readonly instances: number;
  dispose(): void; // removes its meshes from root and disposes them (not the shared parts)
}
BEHAVIOUR:
- Removing swaps the last instance into the hole, so each batch stays dense: count = live instances.
- Capacity starts at 16 and doubles when a batch is full, rebuilding that InstancedMesh with every matrix and tint copied. No per-frame allocation in set or remove once capacity is reached.
- After any change, the batch's boundingSphere covers all its instances, so frustum culling stays right. It may be recomputed lazily, before the next render (onBeforeRender), or at once.
- A batch whose count drops to 0 stays, hidden (count 0), for reuse.
- Every instanced mesh has matrixAutoUpdate false and a name `${key}#${part}`.
Keep this test unchanged; add your own:
```ts
import test from 'node:test'; import assert from 'node:assert/strict';
import * as THREE from 'three';
import { Batcher, type Part } from '../src/index';
const mats = [new THREE.MeshBasicMaterial(), new THREE.MeshBasicMaterial()];
const parts: Record<string, Part[]> = { wall: [{ geometry: new THREE.BoxGeometry(4, 3, 0.25), material: mats[0]! }, { geometry: new THREE.BoxGeometry(4, 0.2, 0.3), material: mats[1]! }], pillar: [{ geometry: new THREE.BoxGeometry(0.4, 3, 0.4), material: mats[0]! }] };
const at = (x: number, z: number) => new THREE.Matrix4().makeTranslation(x, 0, z);
test('batches by key and part, stays dense, keeps matrices and tints through swaps', () => {
  const root = new THREE.Group(); let calls = 0;
  const b = new Batcher(root, (k) => { calls++; return parts[k]!; });
  for (let i = 0; i < 1000; i++) b.set(i, i % 3 ? 'wall' : 'pillar', at(i, i % 7));
  assert.equal(calls, 2); assert.equal(b.drawCalls, 3); assert.equal(b.instances, 1000);
  b.tint(999, new THREE.Color(1, 0, 0));
  for (let i = 0; i < 1000; i += 2) b.remove(i);
  assert.equal(b.instances, 500); assert.ok(!b.has(0) && b.has(1));
  const wall = root.children.find((c) => c.name === 'wall#0') as THREE.InstancedMesh;
  assert.equal(wall.count, [...Array(1000).keys()].filter((i) => i % 2 && i % 3).length);
  for (const id of [1, 5, 999]) { const m = b.matrixOf(id)!; assert.deepEqual(new THREE.Vector3().setFromMatrixPosition(m).toArray(), [id, 0, id % 7]); }
  const slots: number[] = []; for (let s = 0; s < wall.count; s++) { const m = new THREE.Matrix4(); wall.getMatrixAt(s, m); slots.push(new THREE.Vector3().setFromMatrixPosition(m).x); }
  assert.deepEqual([...slots].sort((x, y) => x - y), [...Array(1000).keys()].filter((i) => i % 2 && i % 3));
  const c = new THREE.Color(); wall.getColorAt(slots.indexOf(999), c); assert.deepEqual(c.toArray(), [1, 0, 0]);
  b.set(5, 'pillar', at(-50, -50)); assert.deepEqual(new THREE.Vector3().setFromMatrixPosition(b.matrixOf(5)!).toArray(), [-50, 0, -50]);
  for (let i = 0; i < 1000; i++) b.remove(i); assert.equal(b.instances, 0); assert.equal(b.drawCalls, 0);
  b.dispose(); assert.equal(root.children.length, 0);
});
```
