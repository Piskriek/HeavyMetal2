# W2-B: Cockpit plate, glass, dashboard trinkets and the rope-reel goblin (14 images)

- **Batch**: agent 3 of 7 in art wave 2 (branch `art/generated-wave-2`; the others run at the same time).
  Read [README.md](README.md) first: its prompt, review loop and depth-map steps are binding.
- **Feeds**: tickets P1, P2, X12 and H6.

## Where these are seen (design notes)
Everything here is the cockpit view: the player looks through the windscreen at the track the whole race.
- **The glass** must keep the middle third of the screen clear; grime and glare live at the rim, where a
  real windscreen collects them. Most of each overlay is pure black (invisible with the screen blend).
- **Trinkets** sit on the dashboard at roughly 90–160 px tall on a 1080p screen, next to painted brass
  gauges. They are one family: same camera (front, eye level), same light, same scale logic. Paint the
  sheep bobblehead body first; once it passes review, pass it as a **second reference** for every later
  trinket so the set matches. The three cups are one shape in three metals: pass the passed gold cup as
  the reference for silver and bronze.
- **The rope-reel goblin** is a small character in motion: a clear pose per frame beats detail.

## Rules for this batch
- Each image lists its own process. Keyed sets (`cockpit`, `cockpit-trinkets`) run the edge repair
  themselves; never run the fixer by hand after them.
- The glass overlays (2–4) are **not** magenta: light marks on pure black, resized with ImageMagick.
- The rope-reel sheet (13) is the only image that edits code (`SHEETS`).
- Run the README's **review loop** on every keyed image (the glass overlays: look at them over a dark
  screenshot-like background instead; nothing may cover the middle third).
- The builder's Custom 3D icon moved to W2-E, so it matches the other builder icons.
