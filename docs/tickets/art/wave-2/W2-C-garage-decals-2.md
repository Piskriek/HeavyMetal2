# W2-C: Ball Garage decal pack 2 (16 images)

- **Batch**: agent 4 of 7 in art wave 2 (branch `art/generated-wave-2`; the others run at the same time).
  Read [README.md](README.md) first: its prompt, review loop and depth-map steps are binding.
- **Feeds**: the Ball Garage's decal catalog (ticket X13, wired by ART-I2).

## Where these are seen (design notes)
Decals are stamped onto a lit 3D ball: large in the Ball Garage (about 300 px), tiny in a race (about 40 px on
screen, spinning). The garage **tints** each decal, so the design lives in its values (white, pale grey, dark
outline), never in hue. A good decal is one bold silhouette you could recognise filled in black. The game
already has a flaming skull, crossed wrenches, a gear, a fist and a trefoil, so this pack avoids more skulls
and gears and leans into racing: flames, lightning, the comet marble, the armored sheep.
Bands wrap around the ball, so their left and right ends must join invisibly.

## Rules for this batch
- Every image: **Raw** `art-src/garage-decals/raw/<id>.png`, then
  `node --import tsx scripts/key-art.ts --set garage-decals --only <id>` → PASS (bands: WARN "tileable band" is expected).
- Pass the image's **Reference** as the image input. Run the README's **review loop**; for decals the 48 px
  check is the one that matters.
- Bands: the prompt asks for exactly three repeats. Before keying, crop the raw to a whole number of repeats
  so the left and right columns match (compare with a small fuzz; painted shading is never pixel-exact).
- Ids changed from the first draft: `emblem-goblin-skull-grin` is now `emblem-marble-comet` (too close to the
  existing flaming skull).
