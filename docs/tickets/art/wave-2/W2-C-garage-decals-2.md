# W2-C: Ball Garage decal pack 2 (16 images)

- **Batch**: agent 4 of 4 in art wave 2 (PR branch `art/generated-wave-2`; the other three run at the
  same time). Read [README.md](README.md) first, and the wave-1 README's Part A (the rules still apply).
- **Feeds**: the Ball Garage's decal catalog (ticket X13, wired by ART-I2).

## Rules for this batch
- Every image: **Raw** `art-src/garage-decals/raw/<id>.png`, then
  `node --import tsx scripts/key-art.ts --set garage-decals --only <id>` → PASS (band decals: WARN "tileable band" is expected).
- Band decals (`pattern-*`) must tile: crop the raw to whole repeats so the left and right columns match
  (compare with a small fuzz, painted shading is never pixel-exact).
