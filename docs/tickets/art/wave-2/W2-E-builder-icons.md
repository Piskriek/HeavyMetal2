# W2-E: painted builder shelf icons (primitives and lights) (16 images)

- **Batch**: agent 6 of 6 in art wave 2 (branch `art/generated-wave-2`; the others run at the same time).
  Read [README.md](README.md) first, and the wave-1 README's Part A (the rules still apply).
- **Why**: the builder's Primitives and Lights shelves use vector line icons; the owner wants painted art.

## Rules for this batch
- Every image: **Raw** `art-src/ui/raw/<id>.png`, then `node --import tsx scripts/key-art.ts --set ui-icons --only <id>` → PASS.
- Keep all 16 in one family: same three-quarter view, same lighting, same fill.
