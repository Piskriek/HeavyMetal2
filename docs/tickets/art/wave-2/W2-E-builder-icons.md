# W2-E: Painted builder shelf icons (17 images)

- **Batch**: agent 6 of 7 in art wave 2 (branch `art/generated-wave-2`; the others run at the same time).
  Read [README.md](README.md) first: its prompt, review loop and depth-map steps are binding.
- **Feeds**: the builder's Primitives and Lights shelves (vector line icons today) and its Custom 3D card.

## Where these are seen (design notes)
The builder's shelves show these at about 56 px on dark zinc tiles with amber highlights (the builder's own
"Forge" look). A shelf icon has one job: **say the shape** (box, sphere, cone…) or the light it makes, at a
glance. So the geometry comes first and the goblin material second, every icon uses the same camera and
light, and a warm rim light keeps dark iron from vanishing into the dark tile. They are one family:
paint `builder-prim-box` first; once it passes review, pass it as the **second reference** for every other
icon. Lights must not glow outside their outline (a halo on magenta keys into a pink fringe).

## Rules for this batch
- Every image: **Raw** `art-src/ui/raw/<id>.png`, then `node --import tsx scripts/key-art.ts --set ui-icons --only <id>` → PASS.
- Run the README's **review loop**, and also look at all passed icons side by side at 56 px on `#27272a`:
  `montage -background '#27272a' -geometry 56x56+6+6 public/art/ui/icons/builder-*.png art-src/review/shelf.png`.
  Any icon that reads as a different family (camera, light, outline weight) is regenerated.
- Image 17 (`custom-model`) moved here from W2-B so it matches the shelf. The code already points at it.
