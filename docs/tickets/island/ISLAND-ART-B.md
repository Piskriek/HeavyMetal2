# ISLAND-ART-B: 16 reference images: palms, rocks, secret spots, ball armour

Same purpose, rules, style block and review as [ISLAND-ART](ISLAND-ART.md) (read it first; everything there
applies here). These images become Meshy models for the island's dressing and its **secret spots**: small
scenes a player spots from a branch and remembers ("did you see the skeleton?"). That is the magic the owner
wants, so every set piece must tell its little story at a glance.

The owner lifted the "no foliage" rule for these: palm trees and rocks are wanted now.

## Extra rules
- **No lettering anywhere.** Signs, banners and labels are painted blank; the game writes the words on them.
- Set pieces are one grouped object on a small sand or basalt base, so they place as a single model.
- Ball armour (#14–16) is modelled **around an empty sphere**: the sphere is shown as a plain smooth grey ball
  (the game draws its own ball there); only the armour is the subject.
- Reference images: `art-src/meshy/refs/basalt-cave.png` for stone and set pieces,
  `art-src/meshy/refs/boardwalk-bridge.png` for timber and iron. Reject any try that copies their shape.
