# X12: Dashboard Trophies and Bobblehead Customization

- **ID**: `X12`
- **Priority**: Creative Proposal
- **Component**: Cockpit Customization / Collectibles / Physics Props
- **Conflicts with**: None
- **Needs art**: Yes (Small painted bobblehead and dashboard trinket sprites)

---

## Goal
Add collectible, physics-reactive dashboard trinkets and bobbleheads mounted on top of the cockpit dashboard in first-person view. Winning tournament cups, beating course time records, and pulling off crazy stunts unlocks dashboard decor—such as a bobbling sheep mascot with jiggling head, a swinging brass fuzzy dice pair that sways with lateral $G$-forces, a smoking mini goblin rocket, and golden tournament cups. The trinkets physically react to acceleration, jumps, and sharp steering inputs using spring-damper physics.

---

## Acceptance Criteria
- [ ] Players can equip up to 2 dashboard trophies/bobbleheads in the Workshop/Setup screen.
- [ ] Equipped trinkets render inside the cockpit dashboard aperture with realistic inertia bobbing and swaying.
- [ ] Winning tournaments unlocks unique prestige dashboard trophies.
