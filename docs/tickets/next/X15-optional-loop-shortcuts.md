# X15: Optional High-Risk Loop Shortcuts

- **ID**: `X15`
- **Priority**: Creative Proposal
- **Component**: Track Design / High-Risk Shortcuts / 3D Geometry
- **Conflicts with**: None
- **Needs art**: No

---

## Proposal
While standard roller coaster loops serve as grand visual scenery along the main track, introduce high-risk optional loop-the-loop branch paths authored directly in the lane network. Approaching the loop section, an elevated spur path forks off the main corridor requiring minimum threshold speed ($v_x > 280$) or a well-timed turbo boost to enter. Successful riders loop vertically through the 3D wooden structure, grabbing supercharged air pickups and bypassing a slow hairpin turn to emerge seconds ahead; failing to maintain speed causes the marble to stall, fall off the rails into a cliff hazard, and trigger a rope recovery penalty.

---

## Acceptance Criteria
- [ ] At least one authored course features an optional branch path entering a full vertical 3D loop.
- [ ] Entering the loop with sufficient speed traverses the vertical loop track space and exits ahead of the main route.
- [ ] Under-speed entry drops the marble and triggers standard hazard recovery.
