# Meshy island reference images

These are clean, shape-first 3D concept references for a new island stunt map.

- `island-overview-01.png` — macro island layout, summit descent, bridge crossover, loop and waterfall cave.
- `mountain-track-cutaway-01.png` — cutaway terrain with multiple route heights and underground track.
- `stunt-object-kit-01.png` — isolated loop, scaffolding, ramps, bridge, portals and landing deck.
- `terrain-modular-kit-01.png` — modular terrain chunks, route sections, supports, guard rails and side boxes.

Use the overview and cutaway to explain the world; use the two kit sheets as shape references for individual Meshy generations. These images intentionally omit foliage, vehicles, crowds, text and decorative clutter so the 3D silhouettes stay readable.

The detailed handoff, scale ratios, axis/pivot rules, import caveat and suggested asset breakdown are in [`docs/MESHY_ISLAND_REFERENCE_PLAN.md`](../../../docs/MESHY_ISLAND_REFERENCE_PLAN.md).
